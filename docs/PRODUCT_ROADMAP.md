# AtlasIQ Product Roadmap\n\n> The original MVP milestones have largely landed. The active priority is consolidation before additional breadth.\n\n## P0 — Core Hardening\n\n- QIR v2 schema, stable identities and provenance\n- parser/contributor SPI and registry\n- canonical metadata for reproducible diffs\n- Flyway-managed schema and query indexes\n- E2E quality gates for scan, multi-repo, diff, blast radius and PR impact\n- frontend component/design-system extraction\n- health, metrics, tracing and structured operational telemetry\n- bounded scans, benchmarks and asynchronous job execution\n\n## P1 — Architecture Knowledge Graph depth\n\nDirected impact semantics, richer provenance, graph traversal, critical paths, hotspots and runtime correlation.\n\n## P2 — Product intelligence\n\nService catalog depth, runtime intelligence, grounded Copilot, PR intelligence and architecture governance.\n\n## P3 — Enterprise hardening\n\nDurable tenancy/RBAC/audit, SCIM, API keys/service accounts, signed webhooks, quotas, usage metering and provider-backed billing/licensing.\n
